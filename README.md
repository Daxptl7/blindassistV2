# BlindAssist V2 — Android Companion

Native Android companion application for the standalone BlindAssist Raspberry Pi terminal.

**Repository status:** Android Phase 3 foundation. Raspberry Pi terminal, command broker, and communication gateway are **not present in this repository**. No BLE, Wi-Fi, or remote terminal control is implemented yet.

Android sources are under [`android-app/`](android-app/). See [`docs/MOBILE_PHASE3_ANDROID_ARCHITECTURE.md`](docs/MOBILE_PHASE3_ANDROID_ARCHITECTURE.md) once the Phase 3 scaffold is added.

Design requirements: accessible to TalkBack, English/Hindi/Gujarati translations, no gradients, square-corner action buttons, and truthful disconnected status.
