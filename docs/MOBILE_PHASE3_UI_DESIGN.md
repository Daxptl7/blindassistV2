# Phase 3 — UI design

- No gradients or decorative neon effects.
- Square-corner action buttons (`RectangleShape`).
- Flat, high-contrast light and dark color schemes.
- All primary screens use heading semantics.
- Navigation uses Material3 NavigationBar with text labels.
- Input controls have 48dp+ interactive surfaces where practical.
- Language text: English, Hindi and Gujarati via `res/values*` string resources and per-language configuration contexts.
- The Devices screen truthfully reports that communication has not been implemented.
- The Features page is an informational catalog, not a claim that remote controls work.

Manual contrast and TalkBack checks have **not** been completed and remain required before release.
