# Phase 3 — Accessibility checklist

Implemented at source level: plain-language status text, screen headings, labeled navigation items, full-width action buttons with square corners, and translated UI strings.

**Still requires real-device verification:**
- TalkBack focus order and announcements after navigation.
- 200%+ text scaling without clipping, especially bottom navigation.
- Color contrast in both themes.
- Hindi and Gujarati screen-reader pronunciation and text wrapping.
- 48dp touch target evaluation for all controls.
- Screen rotation and app restart.
- System accessibility scanner findings.

A source-level accessibility design is not equivalent to validated TalkBack behavior.
